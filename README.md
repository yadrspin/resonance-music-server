# Resonance — Музыкальный сервер с Folder-First структурой для Windows

Resonance — это автономный легковесный веб-сервер и аудиоплеер, предназначенный для воспроизведения музыки со строгим сохранением структуры папок на диске (без авто-пересортировки по тегам исполнитель/альбом).

---

## 🚀 Быстрый запуск на Windows (в 1 клик)

1. Убедитесь, что у вас установлен **Node.js (LTS)**:
   Скачать можно бесплатно с официального сайта: [https://nodejs.org/](https://nodejs.org/)
2. Распакуйте архив в удобное место (например, `C:\Resonance`).
3. Дважды кликните по файлу **`start-windows.bat`**.
   - Скрипт сам установит необходимые пакеты и запустит сервер.
4. Откройте в браузере:
   👉 **http://localhost:3000**

По умолчанию сервер откроет вашу папку `C:\Users\<ИмяПользователя>\Music`.

---

## 📁 Как указать другую папку с музыкой (например, диск D:\)

В командной строке или PowerShell перед запуском укажите путь:

### В командной строке (CMD):
```cmd
set MUSIC_DIR=D:\Музыка
npm start
```

### В PowerShell:
```powershell
$env:MUSIC_DIR = "D:\Музыка"
npm start
```

## 🐳 Запуск через Docker Desktop на Windows

Если у вас установлен Docker Desktop:
1. В файле `docker-compose.yml` укажите путь к вашей папке с музыкой:
   ```yaml
   volumes:
     - D:/Музыка:/music:ro
     - ./resonance_data:/data
   ```
2. Запустите в терминале:
   ```bash
   docker compose up -d
   ```
3. Откройте **http://localhost:3000**

## 📱 Как слушать с телефона по домашнему Wi-Fi

1. Узнайте IP-адрес компьютера в локальной сети: выполните команду `ipconfig` в терминале (строка «IPv4-адрес», например `192.168.1.45`).
2. Разрешите порту 3000 принимать подключения в Брандмауэре Windows (выполните в PowerShell от Администратора):
   ```powershell
   netsh advfirewall firewall add rule name="Resonance Music Server" dir=in action=allow protocol=TCP localport=3000
   ```
3. Откройте на телефоне браузер и введите:
   **http://192.168.1.45:3000** (подставьте ваш IP).
