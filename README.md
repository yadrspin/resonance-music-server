# Resonance — Музыкальный сервер с Folder-First структурой для Windows

Resonance — это автономный легковесный веб-сервер и аудиоплеер, предназначенный для воспроизведения музыки со строгим сохранением структуры папок на диске (без авто-пересортировки по тегам исполнитель/альбом).

---

## 🚀 Быстрый запуск на Windows (в 1 клик)

1. Убедитесь, что у вас установлен **Node.js (LTS)**:
   Скачать можно бесплатно с официального сайта: [https://nodejs.org/](https://nodejs.org/)
2. Распакуйте архив в удобное место (например, `C:\Resonance`).
3. Дважды кликните по файлу **`start-windows.bat`**.
   - Скрипт сам установит необходимые пакеты и запустит сервер.
4. Откройте в браузере:
   👉 **http://localhost:3000**

По умолчанию сервер откроет вашу папку `C:\Users\<ИмяПользователя>\Music`.

## ⚙️ Установка и удаление сервера как службы Windows

Если вы хотите, чтобы сервер работал всегда в фоновом режиме и **автоматически запускался при включении компьютера** (без открытого черного окна консоли):

### Установка службы:
1. Запустите файл **`install-service.bat`** (или правой кнопкой мыши -> «Запуск от имени администратора»).
2. Скрипт сам запросит подтверждение прав администратора (UAC), скомпилирует проект и зарегистрирует службу Windows **`ResonanceMusicServer`**.
3. Сервер запустится в фоновом режиме и будет автоматически стартовать вместе с Windows.
4. Проверить статус службы можно в диспетчере служб: нажмите `Win + R`, введите `services.msc` и найдите **Resonance Music Server**.

### Удаление службы:
1. Запустите файл **`uninstall-service.bat`** от имени администратора.
2. Скрипт корректно остановит фоновый процесс и полностью удалит службу из Windows.

## 📁 Настройка путей и порта (Файл config.json)

В корне проекта есть конфигурационный файл **`config.json`** (или `config.example.json`). Откройте его в обычном Блокноте:

```json
{
  "musicDir": "N:\\muz",
  "port": 3000,
  "dataDir": ""
}
```

- **`musicDir`**: Путь к вашей музыкальной коллекции (например, `"N:\\muz"` или `"D:\\Музыка"` или `"N:/muz"`). Если оставить пустым `""`, сервер откроет стандартную папку музыки Windows (`C:\Users\<Имя>\Music`).
- **`port`**: Порт для веб-сервера (по умолчанию `3000`).
- **`dataDir`**: Папка для базы данных плейлистов (по умолчанию `%APPDATA%\ResonanceServer`).

Настроив `config.json` один раз, вам больше **не нужно указывать пути каждый раз при запуске** — и обычный запуск через `start-windows.bat`, и служба Windows автоматически прочитают ваши настройки!

## 🐳 Запуск через Docker Desktop на Windows

Если у вас установлен Docker Desktop:
1. В файле `docker-compose.yml` укажите путь к вашей папке с музыкой:
   ```yaml
   volumes:
     - D:/Музыка:/music:ro
     - ./resonance_data:/data
   ```
2. Запустите в терминале:
   ```bash
   docker compose up -d
   ```
3. Откройте **http://localhost:3000**

## 📱 Как слушать с телефона по домашнему Wi-Fi

1. Узнайте IP-адрес компьютера в локальной сети: выполните команду `ipconfig` в терминале (строка «IPv4-адрес», например `192.168.1.45`).
2. Разрешите порту 3000 принимать подключения в Брандмауэре Windows (выполните в PowerShell от Администратора):
   ```powershell
   netsh advfirewall firewall add rule name="Resonance Music Server" dir=in action=allow protocol=TCP localport=3000
   ```
3. Откройте на телефоне браузер и введите:
   **http://192.168.1.45:3000** (подставьте ваш IP).
